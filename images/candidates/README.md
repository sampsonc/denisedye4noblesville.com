# Candidate Photos

Add professional candidate headshots to this directory:

## Required Files:
- `denise.jpg` - Professional headshot of Denise Dye

## Photo Specifications:
- **Format:** JPG or PNG
- **Size:** 400x400 pixels (square aspect ratio)
- **Quality:** High resolution, professional quality
- **Style:** Professional campaign-appropriate photos
- **Background:** Clean, preferably solid or blurred background

## Tips for Good Campaign Photos:
1. Professional lighting and composition
2. Candidate looking confident and approachable
3. Business attire appropriate for school board
4. Clean, uncluttered background
5. High resolution for web display

## File Naming:
Use exact filenames as listed above - the website expects these specific names.

Once the photo is added, the website will automatically display it in:
- Hero section candidate card
- Detailed candidate profile section
- Navigation and other campaign materials

## Image Optimization:
The deployment script will automatically optimize images for web performance while maintaining quality.
