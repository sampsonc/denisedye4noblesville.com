# Denise Dye for School Board

Campaign website for Denise Dye's 2026 school board campaign in Noblesville, Indiana.

Live site: https://denisedye4noblesville.com

## 🗳️ Website Overview

Professional, responsive campaign website featuring:
- Candidate biographies and qualifications
- Education platform and priorities
- Community endorsements
- Volunteer and contact forms
- Voting information

## 📁 Directory Structure

```
sb/
├── index.html              # Main single-page campaign site
├── css/main.css            # Complete responsive styling
├── js/main.js              # Interactive functionality
├── images/candidates/      # Candidate headshots (add photos here)
├── forms/
│   ├── volunteer.html      # Volunteer signup form
│   └── contact.html        # Contact form
├── deployment/
│   ├── push.sh             # Git deployment script
│   └── copysite.sh         # Full deployment with optimization
├── robots.txt              # Search engine directives
└── README.md               # This file
```

## 🛠️ Development

### Local Testing
Open `index.html` in a web browser to test locally.

### Form Handling
The volunteer and contact forms are ready for backend integration:
- Forms use semantic HTML with proper validation
- JavaScript handles client-side validation
- Ready to connect to email service or form handler

### Deployment

**Git Deployment:**
```bash
./deployment/push.sh
```

**Full Production Deployment:**
```bash
./deployment/copysite.sh --deploy
```
